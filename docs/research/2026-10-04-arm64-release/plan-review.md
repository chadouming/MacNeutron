# Sub-project 5 plan review (2026-10-04)

Three lenses (spec coverage, executability against the code, risk to the maintainer's environment), each re-checked by a sceptic, on the plan draft at `7e7703c`. 65 findings: 63 stood (2 Critical, 28 Important, 33 Minor), 2 were refuted. The revised plan folds in every finding that stood.


# REVIEW 0
Not ready to execute. Most of the spec is covered, and the core names agree with §14 and across tasks: the ToolLayout members, the install signature and outcome, the install verb's exit codes 0/0/3/1, the stamp formats, the `R0b: PASS|FAIL` verdict, the MACNEUTRON_REFERENCE default and the env var names. Gate and test coverage has real holes, though.

- **Gates with no step:** R3's bridge probe on the stripped release wine.app has no step, and neither does L6's spctl/stapler check on an installed notarized copy. Task 14 never records R3, R4 or that L6 half.
- **Tests that can't be written as specified:** Task 8's AppModel tests and Task 7's CLI deferral test have no way to fake a signed source or a running runtime process.
- **Task 12 can't run its own checks:** the R1 tag case can never fire, and Steps 3 and 5 can't run because nothing is pushed and the notary is off-limits until Task 14.
- **Task 6 won't compile as listed:** the SteamPlayModeTests Rosetta references are not in its list.
- **Cross-task contradictions:** smoke.sh lacks the MACNEUTRON_ARM64_APP override that Task 12 relies on, the launcher log line can't use ToolLayout.runtimeLabel, and Task 10 needs a Makefile change it doesn't list.
- **R0b proves less than it should:** it tests a different manifest shape from the one shipped, and its two probes write to the same log.

The fixes below are all edits to the plan text; none needs a spec change.

## R0.0 [Important] Task 8 Interfaces and Step 1 (plan:380-390)

Add `InstalledRuntime(layout:)`, which reads version and identity through an injectable identity closure (default `CodeIdentity.of`). The tests pass a scripted installer: `.deferred("/x")` once, then `.installed`; the fake also writes the fake wine.app's Info.plist. # REVIEW 1
